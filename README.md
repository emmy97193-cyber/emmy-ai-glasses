**The first open-source AI Glasses from Nigeria!**

#### 🔧 Hardware Spec (Like Meta):
- **Right Arm**: Battery 300mAh + ESP32-S3 + Front Camera + Speaker near ear
- **Left Arm**: Battery 300mAh + Button + Speaker
- **Bridge**: Thin enamel wire connecting arms

#### ✨ Features:
- 📸 Take photo with button tap
- 🗣️ "Hey Emmy" voice command
- 👁️ AI sees what you see (GPT-4o Vision)
- 🔊 Speaks answer in your ear
- 📱 Connects to phone via Bluetooth/WiFi

#### 📂 Structure:
- `/firmware` - ESP32-S3 code for glasses
- `/server` - Python FastAPI brain (PythonAnywhere)
- `/images` - Promo photos

#### 🚀 How to make it live:
See full guide in `/firmware/emmy_ai.ino`
